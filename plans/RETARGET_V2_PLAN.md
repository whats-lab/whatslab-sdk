### 0.1 좌우 미러 실측 (통합 판단의 전제)

`tools/check_mirror.py`. 같은 q 를 좌우에 넣고 팜프레임 로컬 사슬 좌표를 `(x, y, -z)` 로
비교한다. **두 실패 모드를 분리해서 잰다** — 섞으면 중립 오프셋이 모든 관절을 오염시켜
전 관절 실패로 보인다(실제로 처음에 robotis 를 20/20 으로 오판했다).

| | 중립형상 | 축 미러오차>2mm | 최악 | 어긋난 관절 |
|---|---|---|---|---|
| human | 4.77mm | **4/21** | 81.9mm | `{index,middle,ring,pinky}_mcp_abd` |
| orca | 0.03mm | **3/17** | 11.2mm | `{I,M,P}-AP_*_to_*Carpals*` (외전축) |
| robotis | 9.79mm | **8/20** | 95.9mm | `finger_?_joint{1,2,5,9,13,17}` 계열 |

- **중립형상** = q=0 에서의 기하 비대칭. 링크 원점·길이가 좌우로 다른 것.
  orca 는 사실상 완전(0.03mm), human 은 4.77mm(엄지 말단 뼈가 1mm 다르다),
  robotis 는 9.79mm 로 전 손가락 균일 → 체계적 오프셋이다.
- **축 미러오차** = 중립을 뺀 변위의 미러 불일치. 회전축 부호/방향 문제만 남는다.
  human 은 정확히 `*_mcp_abd` 4개 — `axis="0 0 1"` 이 좌우 동일한데 축은 의사벡터라
  미러 시 `a' = -M a` 로 부호가 바뀌어야 한다. 오른손 4개만 반전하면 5·15·25° 전부 0.00mm.

이전 세션 기록 두 건은 **틀렸다**: "robotis 는 완전한 미러(0.0mm) / orca 는 35~45mm
어긋남"은 지문 위치만 옛 URDF 로 잰 값, "robotis 20/20"은 중립 오프셋 미분리. 위 표가 정본.

**이전 세션의 형상 43.3° 표도 폐기.** 사람 URDF 관절명이 구버전이라 프로파일과 13/21 이
어긋난 상태의 측정이다. Phase 1 의 "43.3° → 20°" 목표는 §0 새 기준선으로 다시 잡는다.

## 2. 새 방법론으로 폐기된 것

- **f_s 3안 비교(NNS / 학습IK / kp DLS)** — 통합 구조(F 가 q 직접 출력)라 해당 없음.
  측정해 둔 NNS 특성(사전샘플 20배에 오차 19.2→14.8mm, 1↔2위 이웃 q 점프가 밀도와
  무관하게 1.1rad 고정)은 **NNS 를 쓰지 않는 근거**로만 남긴다.
- **`sensor_proximal` 프레임을 prox 로 쓰는 것** — prox 는 **사슬 50% 중앙**으로 바뀐다.
  센서 실장 위치는 손마다 통일 작업이 반복돼 임베디먼트 확장에 약하다.
- **`v_tip→prox` keyvector** — `v_dorsum→{distal,prox}` 로 대체(선형종속 제외).
- **진행 중이던 tip/tip_prox 학습 런** — 키포인트 정의와 FK 가 둘 다 바뀌어 무효.
  (두 번 세션 경계에서 죽기도 했다. 재실행은 새 정의로.)

## 2.5 좌우 모델을 통합할지 — 결론: **통합을 목표로 설계, 도입은 미러 게이트 통과 후**

**통합이 가능한 근거.** 좌우 URDF 가 참 미러라면 팜프레임 로컬에서 왼손 keyvector 는
오른손 keyvector 의 z 성분 부호를 뒤집은 것과 **정확히** 같다(§0.1 의 비교식이 그것이다).
관절 한계도 좌우 동일하고 관절명은 접두사만 다르다. 따라서

```
q_robot = F( mirror_z(keyvector_left) )     # 같은 F, 같은 q
```

가 근사가 아니라 **엄밀한 대칭**이다. 같은 q 를 미러 기구에 넣으면 미러 동작이 나온다는 것을
§0.1 이 측정으로 확인했다(미러가 성립하는 관절에서 오차 0.00mm).

**통합해야 하는 이유 — 대칭성이 공짜로 보장된다.** 비지도 학습은 해가 유일하지 않아
시드마다 흔들린다(GeoRT 는 Ability Hand LMC 36.2±11.2 를 보고했다). 좌우를 **따로**
학습하면 두 손이 서로 다른 국소해에 앉아 **조작자가 왼손과 오른손에서 다른 감각**을 느낀다.
지금 겪는 흔들림과 결이 같은 문제이고, 통합은 이걸 구조적으로 없앤다. 부수 이득으로
학습 데이터가 2배(좌우 글러브 시퀀스를 미러로 합침), 체크포인트·학습시간은 절반이 된다.

**그런데 지금은 도입할 수 없다.** §0.1 대로 human 축 4/21, orca 3/17, robotis 8/20 이
미러가 아니고 중립형상도 human 4.77 / robotis 9.79mm 어긋난다. 미러가 깨진 상태에서
통합하면 한쪽 손의 오차를 다른 쪽에 강제로 떠넘긴다.

**따라서**: Phase 1·2 는 **왼손 side 별 모델**로 진행한다. `tools/check_mirror.py` 가
게이트이고, **손 하나가 축 0/N + 중립형상 2mm 이하가 되면 그 손만 통합으로 전환**한다.
orca 는 중립이 이미 0.03mm 이고 축 3개만 남아 먼저 열릴 가능성이 높다. robotis 는
중립 9.79mm + 축 8개라 더 걸린다 — 손별로 따로 판단한다.

**미러가 영구히 안 되는 손이 나오면** (설계상 좌우가 진짜 다른 경우) 그 손만 side 별
모델을 유지한다. 통합은 최적화이지 전제가 아니다.

## 4. Phase 1 — GeoRT + prox, pinocchio 정확 FK

구현 순서:
1. `ref/planing.md` III 전처리로 keyvector 재정의 — 원점 dorsum, 축 손가락방향 유도,
   prox = 사슬 50% 중앙, `v_dorsum→{distal,prox}` 6D, `L_ref` 상수(identity q=0),
   데이터셋 통계 정규화 없음.
2. **`torch.autograd.Function` 으로 pinocchio FK 랩** — `∂L/∂q = (∂L/∂x)^T · J`.
   신경 FK 제거. 추론 경로에 FK 없음(forward 1회).
3. F = 손가락별 MLP `(6, 128, 128, n_joints_i)`, tanh → `joint_roms` 선형 매핑.
4. 손실은 GeoRT 5원칙 유지(motion / C-space coverage / flatness / pinch / collision).
5. 학습 데이터: 합성(사람 URDF 랜덤) 사전학습 → 글러브 실시퀀스 파인튜닝 2단계.

**판정**: 형상 오차. 목표치는 §0 새 기준선으로 다시 정한다(구 43.3° 는 무효).
**부수 확인**: `|dq|p95`. 시간축이 없으므로 kp 0.072 를 넘기기 어렵다는 것이 사전 예측이고,
대응은 ① EMA 입력 필터 → ② Lipschitz 페널티 → ③ 과거 사람 입력 윈도우(k=2~3) 순서다.
자기 출력 되먹임은 드리프트 위험이라 쓰지 않는다.
